Orthalist

A web application for patients and staff of an orthodontics practice, enabling users to view practice information, manage patient profiles, track medical records, and customize settings.

Live Link

Project Overview

Orthalis is a multi-page web application built using vanilla HTML, CSS, and JavaScript, with the Materialize CSS framework for the interface. The project offers two distinct login areas—one for the practice (staff) and one for patients—each redirecting to a personalized dashboard upon authentication.

✨ Features:

🔐 Authentication
Practice Login (index.html) — access via 8-character ID Patient Login (loginPatient.html) — access via patient code + password
🏠 Home (accueil.html)
Notification feed (appointments, practitioner absences, general information) Practice photo and logo
📍 Practice (cabinet.html)
Practice showcase carousel Contact details (address, phone, email) Opening hours (accordion) Integrated interactive map (Google Maps)
👤 Patient Profile (profil.html)
Personal information form (last name, first name, date of birth, email, phone) Orthodontic progress gallery: before/after photos (frontal and intraoral views)
📁 Medical Record (dossierMedical.html)
Payment history with downloadable invoices Appointment history with downloadable reports Display of outstanding balance
⚙️ Settings (parametres.html)
Language selection (French / English / Spanish) Password change Notification timing adjustment (12h / 24h / 36h / 48h) Text size adjustment Day / Night mode (contrast)
